# Project NAM PRD

## Product Goal
Provide a unified dashboard for product and delivery stakeholders to monitor project execution, sprint health, and release readiness.

## Target Users
- Product managers
- Engineering leads
- Design and delivery stakeholders

## Core Dashboard Requirements
- Show top-level KPIs: active projects, open tasks, utilization, on-time delivery.
- Surface portfolio status with project owner, status, priority, and due date.
- Highlight recent delivery activity and operational risks.
- Include quick controls for search, filtering, and creating a new project.

## Success Metrics
- On-time delivery target: **90%+**
- Team utilization target: **80%+**
- Release readiness confidence displayed each sprint
- Customer impact estimate surfaced for leadership review
